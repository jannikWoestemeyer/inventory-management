Request lifecycle

  1. User changes a filter (warehouse / category / status / month) → useFilters composable updates shared refs.
  2. View component’s computed/watch fires → calls api.getX(filters) in client/src/api.js.
  3. axios issues GET http://localhost:8001/api/... with query params.
  4. FastAPI matches route, validates query, runs apply_filters() + filter_by_month() over in-memory lists.
  5. Pydantic serializes the response → JSON back over CORS to the SPA.
  6. Component renders rows / charts; loading + error states handled per the patterns in client/CLAUDE.md.
